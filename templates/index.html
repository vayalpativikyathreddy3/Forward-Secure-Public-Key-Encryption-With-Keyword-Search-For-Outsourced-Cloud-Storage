Generic Construction From KP-ABE and an Efficient Scheme Over Prime-Order Groups

Expressive Public-Key Encryption with Keyword Search (PEKS) represents an advanced cryptographic innovation by combining the strengths of Key-Policy Attribute-Based Encryption (KP-ABE) and prime-order groups. KP-ABE allows for flexible access policies based on user attributes, enabling the encryption system to manage complex and diverse user permissions effectively. By integrating this with PEKS, the system can perform secure keyword searches within encrypted data without exposing the content, thus preserving confidentiality. The use of prime-order groups enhances the scheme's efficiency and security, as these groups are preferred in cryptography for their straightforward arithmetic properties and robust security guarantees. This hybrid approach allows users to perform detailed and attribute-based keyword searches while maintaining the encrypted state of the data, ensuring both privacy and usability.
